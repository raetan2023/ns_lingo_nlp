# NS Lingo NLP

Corpus-building and NLP exploration project for Singapore National Service (NS) lingo, with a Discord bot (NS Lingo) that explains NS terms using the glossary. The bot runs 24/7 on Google Cloud; see [docs/discord-bot.md](docs/discord-bot.md).

See [docs/README.md](docs/README.md) for full project overview, [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for pipeline details, and [docs/glossary-pipeline.md](docs/glossary-pipeline.md) for glossary file roles and review workflow.
